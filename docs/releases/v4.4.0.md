# 订阅管家 v4.4.0

追加完成五轮 Oil UI 优化，以真实电脑桌面和 Windows 缩放后的可用空间为主。

- 日历事项原位打开账号详情，日期、状态、费用集中查看；关闭后返回原事项和月份。所有已续/未续记录仍保留。
- 母号与拼车成员按账号资料、收费约定横向分组；错误紧邻字段，保存失败保留输入。
- 渠道资料与手续费左右并列；卡片字段区独立滚动，保存区不遮挡字段，未保存关闭可继续编辑或明确放弃。
- 收款录入分组，实收原币与参考折算区分。长备注/付款人紧凑预览、按需展开，右侧操作固定。
- 设置默认双列，邮件展开后使用整行；区分待保存草稿与已生效设置。MFA绑定改为二维码和验证码横排，只有验证完成后显示已开启。

主要验证尺寸：1920×1080、1600×900、1366×768，以及 2560×1440@175% 的1463×823内容空间。较小窗口仅作为压力兼容检查。

原币计算、业务命令、续费/实收分离、卡片本机加密及备份边界保留。公开包不包含私人账本、卡片或凭据。Windows x64，未配置真实发布者代码签名。
