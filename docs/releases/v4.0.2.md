# 订阅管家 v4.0.2

本次加强账本启动检查，并修复订阅页面的渠道筛选。

- 数据库初始化先执行完整性检查，再进行迁移、币种更新等写入。文件或事务日志损坏时停止写入，并给出明确的本地恢复提示。
- 后台停止失败时保留进程引用，后续停止与恢复可继续处理该进程；主动重启不会被误报为后台异常退出。
- “全部渠道”统一处理空值、0 和非法查询参数，避免下拉框显示全部渠道而列表被错误筛空。
- 保留免密进入、旧账本来源映射、国家及首次开通日期、母子同邮箱归并、Pro 仅实际拼车成员，以及历史收支冻结规则。

优先下载 `SubscriptionButler-4.0.2-Setup-Windows-x64.exe`。桌面数据继续保存在 `%APPDATA%\订阅管家`，升级前创建本机加密恢复点。请先退出旧版，再运行新程序。

公开源码和安装包为空账本，不含个人数据或登录配置。程序尚未进行 Windows 代码签名，可通过附带的 `SHA256SUMS.txt` 核验下载文件。
