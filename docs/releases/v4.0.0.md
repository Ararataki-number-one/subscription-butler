# 订阅管家 v4.0.0

本次将 V2 日常运营、V3 经营账本与 V4 多设备协作路线图的功能整合到一个版本。此前公开版本为 v1.0.0，没有另行发布 v2/v3 安装包。

- 今日工作台、通用服务和套餐模板、客户档案、标签分组、全局搜索、日历与批量操作。
- 稳定的位置、客户和租赁编号，加入、续租、退出、换号的历史；续租与实际收款分别登记，重复请求和旧租期版本不能推进两次。
- Business 同邮箱记录归母号；Pro 只管理实际拼车成员；旧记录保留来源，旧表和已确认收款不被迁移重写。
- 统一应收账期、部分收款、补款、退款、优惠、作废和购买费用。历史收支冻结原币与记账汇率，当前预计仍每 5 分钟随汇率更新。
- 分别展示预计收益、现金结余和按期经营收益；支持客户、订阅、日期、渠道筛选和来源明细、年费日分摊、位置权重、固定金额与保本测算。
- CSV 模板、导入预览、重复检查、错误报告和明细导出。
- 托盘运行、到期系统通知、本机加密备份、完整校验恢复、升级前恢复点和回滚保护。
- 手机 PWA、离线队列、记录变更同步、幂等重试与显式冲突处理；管理员、运营、只读和仅自己账期的客户权限。旧版业务与 MFA Server Actions 也在服务端验证身份。

## 使用与升级

优先下载并安装 `SubscriptionButler-4.0.0-Setup-Windows-x64.exe`。安装版从固定目录启动，避免每次临时解压；另提供便携版 `SubscriptionButler-4.0.0-Windows-x64.exe`。程序包含 Node.js 和 SQLite 运行环境，无需安装 Git 或 Node.js。数据继续保存在 `%APPDATA%\订阅管家`；升级前自动创建恢复点。请先退出旧版，再运行新程序。桌面首次打开会自动初始化安全配置并进入工作区，不要求输入密钥。网页访问及协作身份仍需验证。

本机加密备份由 Windows 安全存储保护，只能由原电脑的原 Windows 用户恢复。跨设备使用业务记录同步；MFA、SMTP、本机访问密钥和 Windows 凭据不进入同步。恢复或回滚需要使用兼容备份，不能直接用旧版打开更新版本的数据。

多设备同步中心需自行部署 HTTPS 服务，本项目没有替你开通云服务。连接后先选择明确的初始化方向，旧账本不会仅因填写地址就自动上传。不同独立旧账本的行号相撞会保留冲突，不能当成同一客户自动合并。

程序尚未进行 Windows 代码签名。可用附带 `SHA256SUMS.txt` 验证下载文件。公开包为空账本，不包含个人数据、联系人或密钥。
