# 订阅管家 v4.0.4

本版按桌面使用方式调整常用入口，沿用经典侧栏和已有订阅布局。

- 桌面启动后打开续费日历；首页由原仪表盘改为月历，并列出未来 7 天即将到期和逾期项目。
- 侧栏“订阅”下方新增“客户”，在同一布局内整理客户档案。
- 独立“今日工作台”移出常见桌面入口。订阅页继续保留紧凑列表、按需展开详情及 Business / Pro 汇总布局。
- 既有客户、租赁历史、经营账本、同步和权限能力保留；高级网页工作区继续兼容原网页 / PWA 与运营接口流程。

发布时优先选择 `SubscriptionButler-4.0.4-Setup-Windows-x64.exe`。桌面免密进入，升级前创建本机加密恢复点，数据与可执行文件分开保存。

本版通过 372 项应用测试、40 项桌面测试、13 项成品界面流程，以及运行时、经营接口、同步、网页 / PWA 和加密备份恢复验收。详细范围见 [目标与验收记录](../goal-completion.md)。

公开源码和安装包不含个人账本或登录配置。多设备使用自行部署的 HTTPS 同步中心，公网部署仍需实际验收；中心能读取托管账本，账本端到端加密尚未实施。本机凭证加密与备份加密不等同于端到端加密。
