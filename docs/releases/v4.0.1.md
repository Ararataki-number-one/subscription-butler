# 订阅管家 v4.0.1

本次完善旧账本进入新版工作台时的信息保留与启动检查。

- 订阅保留并显示国家/地区、首次开通日期；编辑和保存时继续保留这些信息。
- 已经迁移的旧订阅会补齐缺失字段，用户自行修改的字段仍按原有所有权规则处理。
- 桌面启动时，在打开工作台前验证本机管理身份并准备旧账本的客户、账号位置与租赁映射；重复启动不会重复生成记录。
- 保留 Business 同邮箱归并、Pro 仅实际拼车成员及历史收支冻结规则。约定收费不自动变成已收款。

优先下载 `SubscriptionButler-4.0.1-Setup-Windows-x64.exe`。安装包包含完整运行环境；桌面免密进入，数据继续保存在 `%APPDATA%\订阅管家`，升级前创建本机加密恢复点。请先退出旧版，再运行新程序。

公开源码和安装包不包含个人账本或登录配置。程序尚未进行 Windows 代码签名；下载文件可通过附带的 `SHA256SUMS.txt` 核验。

多设备同步仍使用自行部署的 HTTPS 中心。同步中心和设备请一同升级到 v4.0.1，以识别新增的国家与首次开通字段；详见仓库中的同步与权限说明。
