# 订阅管家 v4.1.0

- 支付渠道新增“卡片资料”：完整卡号、CVC/CVV、有效期、持卡人姓名、账单国家、地址、邮编及私密备注。
- 敏感资料用 Windows 本机加密保存，按渠道独立管理，不进入普通账本快照、CSV 导出或同步内容。
- 默认隐藏资料，主动显示后 30 秒或切换窗口时自动隐藏；复制内容 30 秒后仅在剪贴板未被其他内容替换时清除。
- 支持修改、并发修改提示和确认删除。加密备份包含卡片资料，恢复旧备份和中断恢复保持兼容。

在“支付渠道”列表右侧点击“卡片资料”开始记录。此功能需要 Windows 桌面版，网页端不保存敏感卡片资料。备份限当前 Windows 用户及电脑恢复。

安装文件：`SubscriptionButler-4.1.0-Setup-Windows-x64.exe`，Windows x64。本版本未配置代码签名。
