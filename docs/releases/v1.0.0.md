# 订阅管家 v1.0.0

首个独立 Windows 桌面版本，下载 `SubscriptionButler-1.0.0-Windows-x64.exe` 即可运行，无需另装 Node.js 或 Git。首次启动设置自己的访问密钥，账本保存在当前 Windows 用户的本地应用数据目录。

- Business 管理母号和子账号出租资料，同邮箱出租记录归母号。
- Pro 只管理实际拼车成员。
- 支付渠道使用列表，支持手续费百分比并计入成本。
- 金额以人民币为主，美元作为补充参考。
- 运行期间每 5 分钟检查汇率，重算当前成本和预计收益；实际收款保留历史记账金额。
- 支持访问密钥、身份验证器双因素认证及 SMTP 到期提醒。

适用 Windows x64。汇率更新和邮件提醒需要软件运行及可用网络。本版本未使用 Windows 代码签名。

下载页同时提供 `SHA256SUMS.txt`、原项目 Apache `LICENSE` 和来源说明 `NOTICE`。公开发布包从空白账本开始，不包含任何个人运营数据。
