# 订阅管家 v4.0.3

本次对照日常运营、经营账本和多设备协作目标补齐使用缺口，沿用现有订阅页面的侧栏、紧凑列表与 Business/Pro 汇总布局。

- 停用订阅的位置不再出现在闲置、分配和换号候选中，原位置与租期历史继续保留。
- 作废账单独立显示作废状态，已收金额按有效收款和退款计算，不将作废误当成已经收款。
- 经营分析随五分钟刷新重算当前估算，并保持最后一次实际计算的筛选条件；历史收支仍使用冻结汇率。
- CSV 预览和错误报告保留原始行号，过滤空行、重复行及跨行字段后仍能定位源文件。
- 设备页提供待上传操作检查、填写原因取消及断开中心入口，按实际权限显示同步操作。
- 离线私有缓存绑定当前已认证浏览器会话；新标签页或缺少成员凭证的会话不能按旧持久身份读取私账。

优先下载 `SubscriptionButler-4.0.3-Setup-Windows-x64.exe`。桌面免密进入，升级前创建本机加密恢复点，数据继续保存在 `%APPDATA%\订阅管家`。

公开源码和安装包不含个人账本或登录配置。多设备使用自行部署的 HTTPS 同步中心；不会自动开通云服务。程序尚未进行 Windows 代码签名，可通过 `SHA256SUMS.txt` 验证下载文件。
