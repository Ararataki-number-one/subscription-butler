# 订阅管家 v4.3.0

继续采用 Oil UI 方法完成五轮界面精修，保留绿色品牌和紧凑布局。

- 订阅详情按账号、支付成本、周期分组；编辑表单减少嵌套边框，长邮箱和窄屏按钮换行更清楚。
- 续费确认显示续费对象、原到期日、下一到期日及含手续费原币成本；实际续费规则与历史保留方式沿用原实现。
- 客户列表统一可读字号、集中搜索与新增；窄屏直接呈现联系方式、使用历史和操作。详情保留客户名称，低频来源信息折叠。
- 币种和汇率表更紧凑；数值显示去掉浮点尾数，计算精度不变；来源说明折叠，设置可直达登录安全。
- 空搜索有就近清除入口；修复客户少量结果时页面垂直居中，窄月历优先显示订阅名。200% 放大与键盘焦点已检查。

数据目录、金额与历史记录、本机加密卡片资料和备份方式保持原实现。公开文件不包含个人账本或卡片资料。

安装文件：`SubscriptionButler-4.3.0-Setup-Windows-x64.exe`，Windows x64。本版本未配置代码签名。
