# 运营工作区

软件启动后进入“今日工作台”。它使用客户、订阅、位置、租赁、账期和收支记录，各自都有稳定编号；改联系方式、换账号不会删除以前的租赁记录。手机或协作成员在 HTTPS 服务的 `/workspace` 使用相同界面。

## 日常处理

1. 在“客户”新增客户，填写联系方式、邮箱、分组和标签。
2. 在“订阅与位置”新增服务和套餐，填原币成本、支付手续费百分比、周期及可用位置。可以把常用套餐保存为模板。
3. 在“租期”分配位置给客户，填加入日期和约定收费。自用位置可不绑定客户，不产生租金收入。
4. 续租会生成下一账期，并保留历史；它不会自动登记已收款。批量续租也会检查每个租期的修订版本，整批有冲突就不推进。
5. 在“收支对账”登记实际收款。支持部分收款和补款，应收、实收、未收分别显示。购买和续费支出填原币金额、手续费及服务期。
6. 退出释放位置并保留历史；换号记录原位置和新位置。退款、优惠、作废需要原因，不能直接删除已记账收支。

Business 保留母号与子账号位置；同邮箱旧子账号归到母号，不重复计算。Pro 保留实际拼车成员，不创建主账号出租位置。旧记录带来源映射；过去未明确绑定账期的收款继续保留“未归属”，不会猜测其租期。

工作台集中展示到期、逾期、待收款和闲置位置。全局搜索可查客户、邮箱、联系方式、账号、标签和记录编号；日历显示订阅续费、租赁到期及应付款日。

## 金额与经营分析

- **预计收益**：现行约定收入减当前成本，每 5 分钟随汇率更新。
- **现金结余**：指定日期内实际收款减退款和实际付款。
- **按期经营收益**：收入及购买成本按其服务期归属到查询日期。年付成本不会全部记到付款当月。

报表可按日期、订阅、客户和支付渠道筛选。展开每一种口径的来源，点击来源查看账期、收支及冻结汇率。历史缺少人民币汇率的记录会注明缺失，不把它当作零金额。

分摊的“按使用天数”按当天实际使用位置的权重分配；“固定位置份额”包含空置位置份额，空置成本保留在订阅。已登记成本保存当时规则，后来更改位置权重不会改写以前的分摊。定价测算使用订阅原币，可比较人数、保本单价和空置影响，不修改账本。

## 导入和导出

“导入导出”提供客户、订阅、收款的 CSV 模板。原币金额填元，日期填 `YYYY-MM-DD`。先预览、处理错误，再确认导入；文件内重复行、以前导入过的相同行及相同文件的重复提交不会重复记账。错误报告可下载。只有管理员可以提交整批导入。

“导出全部明细”包含稳定编号、类型、修订及完整资料，便于核对来源。CSV 会处理电子表格公式前缀；它不是备份恢复包。完整本机恢复使用桌面加密备份，跨设备使用记录同步。

## 离线处理

首次联网打开工作区后，PWA 保存公开程序壳和当前身份的账本缓存。网络连接失败时，可查看最近一次账本，把操作保存到 IndexedDB 待提交队列。尚未提交的操作不计入账本；重新连接后先验证身份，再使用相同操作编号重试。

如果原记录已修改，操作会停在冲突处，不能悄悄覆盖。可以查看新记录后重新操作，或移除本机重试。移除重试不会撤回服务端已经收到的记录。还有未确认操作时，退出身份会提示先提交或逐项处理；退出后清除离线资料缓存。成员凭证只在本次会话保存，重新进入可再次输入。

桌面版即使断开互联网，本机服务仍可保存账本；连接远端同步中心时，远端暂不可用的命令存入本机 SQLite 队列。软件后台定期重试，托盘运行时继续同步。密钥、SMTP 和本机安全配置不进入业务同步。

完整备份/恢复与托盘说明见 [桌面维护](desktop-maintenance.md)，多设备与权限说明见 [同步和权限](sync-and-permissions.md)。
