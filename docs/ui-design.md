# 界面精修约定

方向：保留用户认可的绿色品牌，让订阅、到期事项、客户和当前收益容易核对。平面列表优先，详情按需展开。沿用既有组件与设计变量，不改变账本计算和安全边界。

主色 #0B7157，画布 #F4F6F5，正文 #182C24，辅助文字 #56665E。正文 14px，辅助文字至少 13px。默认侧栏 224px，订阅默认每页 20 条。状态同时使用颜色和文字。

完成五轮：共享布局与列表；订阅详情与表单；客户与租赁阅读；币种汇率与设置；跨页面、空结果、窄屏及200%放大。每轮在虚构账本留基线与修改后截图，做一轮隔离存量润色评审（不打分），再修正并做交互验收。个人账本、备份与私密资料不进入公开仓库。

沿用短时按钮反馈、弹窗过渡及加载反馈，支持减少动态效果偏好。最后一轮删除重复说明、让空结果可恢复。后续保持这一套规范，不为局部页面另起视觉体系。
