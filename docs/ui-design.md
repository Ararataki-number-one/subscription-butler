# 界面精修约定

本文件是现有界面的设计约定。范围为 Windows 订阅与出租账号工作区；先让对象、金额、到期事项与操作容易核对，详情按需展开。

## 已确认的方向

- 用户确认：保留绿色品牌、紧凑订阅列表、小月历、现有导航；客户入口位于订阅下方。
- 用户确认：主要面向电脑横屏。主验收按 2560×1600、175% 缩放对应约 1463×823 内容空间；补查 1920×1080、1600×900、1366×768。
- 用户确认：本次新增 P1–P5 五轮以 v4.4 源码为基线，独立于此前十轮；后续十个功能版本另行实施。
- 用户确认：仅改现有变量和共享组件，不更换组件库，不新增后端接口或数据库迁移。
- 用户确认：金额、手续费、历史汇率、续费、收款、权限及卡片加密规则保持现有业务含义。验证全部使用独立合成账本。

## 视觉基础与共享组件

- Agent 推断（沿用现有实现）：主色 #0B7157，画布 #F4F6F5，正文 #182C24，辅助文字 #56665E；使用 `src/app/globals.css` 的现有变量。
- Agent 推断（现有实现）：正文控件按 14px 层级，辅助文字至少 13px；字体优先现有 Geist，提供中文及系统字体回退。金额采用等宽数字。
- Agent 推断（现有实现）：默认侧栏 224px；订阅每页默认 20 条。沿用共享 Button、Badge、Tooltip、Dialog、Table 和已有焦点环。
- Agent 推断（P1）：页面标题、主要操作、五分钟汇率状态集中在 56px 共享顶栏；每页保留一个有效主标题和一组主操作。详情继续显示对象标题与所在导航。
- Agent 推断（P1）：`src/components/layout/workspace-header.tsx` 负责标题注册与位置；内容区沿用 16/24/32px 响应边距，避免页面再重复占一层标题空间。

## 对象和金额层级

- Agent 推断（P2）：订阅名称、套餐与账号属于同一身份列；邮箱允许必要换行，渠道名称收缩但保留识别尾号，全文可通过鼠标或键盘查看。
- Agent 推断（P2）：人民币为主、美元为辅，原币与手续费置于次级说明。负收益用负号和风险色同时表达；金额不能挤掉到期日及操作。
- Agent 推断（P2）：Business / Pro 汇总明确对应当前筛选，不暗示涵盖其他套餐；排序、分页和过滤继续使用原有数据处理。
- Agent 推断（P4）：客户姓名作为稳定身份；联系方式与邮箱分开阅读。使用中数量与历史租赁数量分别表达，标签、分组与长联系方式允许换行。
- Agent 推断（P4）：展开客户档案先到达其身份与关联记录；收起后回到原位置和触发按钮，空记录说明紧贴对应分区。
- Agent 推断（P5）：支付渠道名称限定在本列，手续费、订阅数量和操作各有独立列；全文按需显示，不能覆盖相邻数字。

## 日历与状态反馈

- 用户确认：所有已续与未续记录都保留在日历；标记已续按原周期推进日期，并保留本期记录。
- Agent 推断（P3）：小月历与近期续费队列并排；日期格优先显示身份，完整账号和费用在浮层、详情及下方列表中阅读。详情关闭保留月份、滚动与焦点。
- Agent 推断（P3）：保留逾期待处理数量和全部月度记录，密集日期格至少显示两条完整事项，其余可滚动查看。
- Agent 推断（P5）：共享状态色由 `src/components/ui/status-tone.ts` 管理。已续为绿色；临期/今日到期和待保存草稿为琥珀色；已逾期/失败为红色；待确认或自用为蓝色；普通状态为中性。
- Agent 推断（P5）：每种状态同时有明确文字，不能仅靠颜色。操作写“标记已续费”，完成事实写“已续费”，两者分开。
- Agent 推断（P5）：待提交明确说明尚未计入账本；普通反馈不用成功绿。失败在表单附近显示并保留输入，提示不得遮住保存、取消或重试。
- Agent 推断（沿用现有实现）：Tab 焦点环独立于侧栏选中色；沿用短时按钮、加载及弹窗反馈，遵从减少动态效果偏好，不为精修新增动画依赖。
