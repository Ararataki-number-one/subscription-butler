# 使用订阅管家

## 首次启动

从本项目 Releases 下载 Windows x64 可执行文件，双击运行。首次启动设置自己的访问密钥，以后用该密钥登录。发布版本会在本机启动服务并打开桌面窗口，无需配置项目路径或安装开发工具。

可在设置中启用身份验证器双因素认证。启用后登录还需输入身份验证器显示的 6 位安全码。登录页的“自动保存密钥”使用当前 Windows 账户加密保存访问密钥。

## 登记订阅与出租资料

先在“基础数据 → 支付渠道”添加支付渠道，填入手续费百分比。例如渠道手续费为 `2.5%`，原币订阅金额为 `100.00`，含手续费成本为 `102.50`。再新建订阅，填写名称、账号、国家或地区、渠道、原币金额、首次开通日与订阅周期。

Business 使用母号和子账号管理。母号也可以出租，填写联系方式、备注、约定收费和下一付款日；子账号固定为 ChatGPT 类型。同一个邮箱既是母号又出现在子账号记录中时，出租记录归母号，避免多算一个账号的收入与分摊成本。

Pro 拼车只登记实际成员。每个成员可以填写联系方式、备注、约定收费、加入日期与付款日；没有额外的“主账号”出租记录。

“续费”用于推进订阅或成员的周期。约定收费表示预计收入；实际收到款项后，应登记真实收款，不要仅凭约定金额判断已经到账。

## 当前金额与历史收款

| 项目 | 汇率更新后的行为 |
| --- | --- |
| 当前订阅成本 | 按原币金额、手续费百分比和最近汇率重新折算 |
| 当前约定出租收入 | 按约定原币金额和最近汇率重新折算 |
| 当前预计收益 | 根据更新后的收入与分摊成本重新计算 |
| 已登记的实际收款 | 保留该笔收款当时的记账金额 |

金额默认以人民币显示，美元作为补充参考。详情保留原币金额、手续费、含手续费合计及汇率来源，以便核对。

程序运行期间每 5 分钟检查汇率，各页面自动刷新当前金额，也可以在“汇率”页手动刷新。上游报价有自己的发布周期，因此“报价日期”可能早于“最近检查时间”；检查成功但报价未变化时，金额也不会变化。网络或来源暂时不可用时，软件沿用最后成功保存的汇率。没有可用汇率的币种需要补齐后才能完成折算。

## 邮件提醒

在设置中分别配置订阅到期提醒和成员付款提醒，填写接收邮箱、SMTP URL、发件邮箱、发送时间与模板，然后用测试按钮确认配置。提醒发送依赖软件正在运行和可用网络。

## 数据备份与升级

使用软件菜单打开数据目录。数据保存在当前 Windows 用户的应用数据目录，升级可执行文件不会把账本写进公开仓库。

备份时先退出软件，再复制整个数据目录，连同安全配置一起妥善保存。SQLite 在运行中可能存在日志文件，直接只复制一份打开中的数据库可能不完整。

升级前保留备份，再下载新版本启动。若反馈问题，请提供版本号、操作步骤和错误提示；公开 Issue 中请隐藏邮箱、联系人、金额明细、SMTP 配置与访问密钥。
